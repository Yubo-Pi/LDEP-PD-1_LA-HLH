# Download the companion dataset

Copy `data/LDEP_PD1_LA-HLH_deidentified.csv` and `data/data_dictionary.csv`
from the companion Zenodo data package into this directory. The CSV has
24 subjects and 118 columns. Data files are intentionally ignored by Git.

The Zenodo record DOI/URL has not yet been assigned. The repository owner
should add the published record link to the root README when available.
